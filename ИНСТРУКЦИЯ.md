# Атриум — как запустить на своём компьютере

Учебный реестр клиентов и договоров юридической компании. Это сайт: отдельная программа и отдельный сервер базы данных не нужны.

## Что установить

1. [Node.js 22](https://nodejs.org/) — вместе с ним ставится npm.
2. Любой современный браузер.

Python, C++ и PostgreSQL ставить не нужно. База поднимается из файлов в папке `migrations`.

## Запуск

Скачайте проект и откройте его папку:

```bash
git clone https://github.com/michael7I952I812I52NGG/atrium-registry.git
cd atrium-registry
npm install
npm run dev
```

Откройте в браузере [http://localhost:8080](http://localhost:8080).

Окно входа — для отдела документооборота. Регистрации с сайта нет: учётки уже созданы.

## Логины и пароли

Пароли учебные. Репозиторий открытый, поэтому логины видны всем.

| Должность | Логин | Пароль | Что можно |
| --- | --- | --- | --- |
| Администратор | admin@atrium.test | Atrium-Admin-2026 | Всё, включая админку и смену должностей |
| Руководитель отдела | lead@atrium.test | Atrium-Lead-2026 | Клиенты, договоры, статусы, печать, чат |
| Юрист | lawyer@atrium.test | Atrium-Lawyer-2026 | Просмотр клиентов, договоры и статусы, печать, чат |
| Делопроизводитель | clerk@atrium.test | Atrium-Clerk-2026 | Клиенты и договоры, печать, чат. Статус не меняет |
| Помощник юриста | assistant@atrium.test | Atrium-Assist-2026 | Черновики договоров, печать, чат. Статус и клиентов не правит |
| Архивариус | archivist@atrium.test | Atrium-Archive-2026 | Только просмотр, печать и чат |
| Экспедитор | courier@atrium.test | Atrium-Courier-2026 | Список договоров, печать и чат. Клиентов не видит |

В чате сотрудник пишет только от своей должности. Администратор может писать от любой.

Админка: после входа администратора пункт «Админка». Там видны допуски и можно сменить должность другому сотруднику.
